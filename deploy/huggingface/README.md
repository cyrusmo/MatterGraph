# MatterGraph Grounded Explorer

Natural-language requirements become confirmed, versioned constraint plans executed over a frozen
25,000-record `compatible_pbe` LeMat-Bulk index. The application shows the live feasible design
space, exact exclusion reasons, source-backed crystal structures, missing-evidence states, and
index-relative Pareto-minimal recovery paths.

Scientific boundary: the language interpreter proposes a plan; deterministic public code owns
validation, execution, missingness, and recovery. Recovery paths are relative to the frozen index
and are not causal claims. The renderer displays source-backed atoms and unit cells without
inferring chemical bonds.

The Space retains neither raw prompts nor provider outputs. Private replays stay in the browser;
server replay requires explicit opt-in.

Source: [cyrusmo/MatterGraph](https://github.com/cyrusmo/MatterGraph).

Application code is Apache-2.0 licensed. The frozen data artifact retains the upstream
LeMat-Bulk dataset license and attribution recorded in `index_v1.manifest.json`.
